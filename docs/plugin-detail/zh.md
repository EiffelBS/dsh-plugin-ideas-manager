# 想法看板

在 DSH 界面中维护想法积压库，在看板上分类，然后把选中的想法直接变成一次真实执行。

## 打开看板

在侧边栏“新建会话”下方选择 **想法看板**。看板是普通的全局面板：切换到其他
面板会关闭它，侧边栏行上的角标显示 **待评审** 中有多少条想法。

## 捕获与分类

- **新想法**（或“打开”列顶部的快速输入行）需要一个标题，另可填写 Markdown
  描述、标签和建议排名。
- **AI 捕获** 会把草稿交给新的分析会话，并切换到该会话。分析完成后，它会将
  卡片写回看板，包含分析、改进后的标题、标签、价值/工作量评分和建议排名。
- 每张卡片都显示稳定编号、工作区、标签、价值/工作量徽章和更新日期。可在四
  列之间拖拽卡片——**打开**、**待评审**、**已归档**、**已拒绝**——或在列内
  重新排序。
- **搜索** 和标签筛选作用于整个看板。**优先级** 标签页展示排名，**已交付**
  展示通过的条目，**健康度** 为每个积压问题给出一行式回答。

## 运行一个想法

**启动** 会将该想法作为一次执行启动。安装 TaskBoard 插件时，一张 TaskBoard
卡片会镜像该想法，执行发生在那里；否则插件会在该想法的工作区内直接打开会话。
已启动卡片上的 **打开会话** 会回到处理它的会话，评审环节决定结果是交付还是
退回。

## 设置

看板标题栏的齿轮按钮会打开 DSH 设置窗口中本插件的分区：显示选项（默认标签
页、排序、卡片密度、语言、Markdown 渲染、陈旧阈值）、**备份**（带时间戳的
快照、恢复、可移植导出与导入）以及 **关于**。

## 要求

- DSH 界面 0.1.5-rc.1 或更新版本。
- TaskBoard 插件是可选的；没有它想法看板也能正常工作。
- 账本由宿主持有（`~/.dsh/ideas/ledger-v2.json`）；代理和界面通过插件的
  `/api/ideas` 路由读写它。
